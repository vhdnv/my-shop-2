# تصميم محل هواتف وأكسسوار وصيانة — «سمارت بوينت»

ملف عرض تصميم كامل (واجهة خارجية + داخلي + مخطط + مواصفات + تكلفة) لمحل بيع وشراء وصيانة هواتف
بمساحة ≈ 11 م²، مبني على صور الموقع والاسكتش اليدوي المرسل.

## التشغيل

```bash
python3 -m http.server 8080 --bind 0.0.0.0 --directory design
```

ثم افتح `http://localhost:8080`.

للحصول على ملف PDF: افتح الصفحة في المتصفح ثم `Ctrl/Cmd + P` → «حفظ كـ PDF» (تنسيق الطباعة مضبوط مسبقًا).

## المحتوى

- `index.html` — العرض الكامل (عربي RTL، بلا أي اعتماد خارجي).
- `assets/exterior-day.jpg` / `exterior-night.jpg` — تصور الواجهة نهارًا وليلًا.
- `assets/interior-main.jpg` / `interior-accessories.jpg` / `interior-repair.jpg` — تصور الداخل.
- `assets/site/` — صور الموقع الأصلية (قبل).
- `assets/logo.svg` — الشعار المقترح (SVG قابل للتعديل).

## فروض المقاسات

| البند | القيمة |
|---|---|
| صافي الواجهة بين العمودين | 2.60 م |
| العمق | 4.20 م |
| الارتفاع الصافي | 3.05 م (≈ 2.85 م بعد السقف) |
| المساحة الصافية | ≈ 10.9 م² |
| باب المحل الحالي | 1.32 × 2.12 م |

كل الأرقام تُثبَّت بعد الرفع الميداني بالمتر الليزر قبل تنفيذ الألومنيوم أو النجارة.
